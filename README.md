
# 🚀 To_Do_App_Flutter  
A beautifully designed, fast, and beginner‑friendly **Flutter To‑Do Application** that allows users to manage tasks with ease.  
This project demonstrates clean UI/UX, structured state updates, date picking, and smooth task management.

---

# 🌟 Features Overview

### ✅ Core Features
- Add tasks with:
  - **Title**
  - **Description**
  - **Due Date**
- Edit existing tasks seamlessly
- Delete tasks instantly
- Responsive bottom input panel (no scrolling required to add tasks)
- Modern, eye‑catching gradient UI
- Clean animations & smooth task updates

### 🎨 UI/UX Features
- Material 3 design
- Gradient AppBar
- Beautiful task cards
- Shadowed bottom sheet input form
- Icon‑based intuitive design
- Works on all screen sizes

# 🛠️ Getting Started

### 1️⃣ Clone The Repository
```
git clone https://github.com/tanishqkolhatkar93/To_Do_App_Flutter.git
```

### 2️⃣ Navigate Into Project Folder
```
cd To_Do_App_Flutter
```

### 3️⃣ Get Dependencies
```
flutter pub get
```

### 4️⃣ Run the App
```
flutter run
```

# 🎯 How To Use

### ➕ Adding a Task
- Enter Task **Title**
- Enter **Description**
- Pick a **Due Date**
- Tap **Add Task**

### ✏️ Editing a Task
- Tap the ✏️ icon
- Edit fields
- Tap **Update Task**

### 🗑️ Deleting a Task
- Tap the 🗑️ icon
